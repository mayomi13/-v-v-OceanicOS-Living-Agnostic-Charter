This repository contains the Living Agnostic Charter and a reference full-stack implementation scaffold.

To bootstrap locally (requires Node.js and Docker):

1. Install dependencies for workspace (optional):

```bash
npm run bootstrap
```

2. Start services with Docker Compose:

```bash
docker-compose up --build
```

- Backend API: http://localhost:3000/health and /charter
- Frontend: http://localhost:5173
