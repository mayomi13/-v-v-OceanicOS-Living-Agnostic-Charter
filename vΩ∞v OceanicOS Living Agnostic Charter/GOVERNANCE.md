# Governance

## Overview
This project follows a lightweight, meritocratic governance model focused on open collaboration and transparent decision-making.

## Roles
- Maintainers: Individuals with commit access who manage releases, review PRs, and make day-to-day decisions.
- Contributors: Anyone who submits issues, PRs, or documentation updates.

## Decision-making
- Minor changes: merged by maintainers after review.
- Major changes: proposals must be discussed via issues and documented PRs; consensus-seeking with maintainers and community members.

## Proposals
- Create an issue with the `proposal` label.
- Discuss and iterate in the issue thread.
- Submit a PR with the proposed changes and link the proposal issue.

## Onboard new maintainers
- Candidates are nominated in an issue and must be approved by existing maintainers.

## Amendments
- Changes to governance itself must follow the proposal process and be clearly documented.
