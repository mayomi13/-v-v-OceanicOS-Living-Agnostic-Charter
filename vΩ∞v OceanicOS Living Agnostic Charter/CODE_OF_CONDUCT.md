# Code of Conduct

We expect all contributors to follow a respectful, welcoming, and inclusive code of conduct.

- Be kind, courteous, and considerate in all interactions.
- Focus on ideas, not individuals; be constructive in criticism.
- No harassment, discrimination, or abusive behavior.

If you encounter issues, open an issue or contact the maintainers.

This is a short summary; projects may adopt a formal Code of Conduct (e.g., Contributor Covenant) if desired.
