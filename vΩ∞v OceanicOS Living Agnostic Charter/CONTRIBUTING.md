# Contributing

Thanks for your interest in contributing to vΩ∞v OceanicOS. We welcome contributions of all kinds.

## How to contribute
- File an issue to report bugs or request features.
- Fork the repo and open a pull request for code or doc changes.
- Use clear descriptions and link related issues.

## Pull request process
- Use a descriptive branch name, e.g., `feature/your-feature` or `fix/issue-123`.
- Run any tests and linters locally if present.
- Provide a clear PR description and note breaking changes.

## Coding standards
- Be concise and maintain consistency with existing style.
- Document public-facing behavior in the README or inline docs.

## Communication
- Use issues for discussion; mention maintainers when needed.
- Be patient and responsive to review feedback.
